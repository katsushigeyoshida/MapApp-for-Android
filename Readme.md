## いろんな地図(MapApp) - 地図表示

国土地理院で公開している地図を主体にいろいろな地図を表示する。  
あらかじめ登録している以外の地図も登録でき、地図同士の重ね合わせを行うことができる。  
GPSのトレース機能も併せ持つ。  
旧版のMapAppを新しい開発環境(Android Studio Narwhal)で再作成。  
大きな変更はGPSデータファイルなどを共通ストレージ(/strage/emulated/0/DCIM/mapapp)に変更、あと細かいところを修正。  
文末にインストール方法を記載している。  

### 機能
・国土地理院の地図データなどをいろいろな地図を表示する  
・地図同士の重ね合わせが可能で、気象庁の雨雲の動きや地滑り地形分布図の表示が可能
・GPSデータを取得して異動した経路を表示する  
・GPSのトレースデータをタイトルやコメントなど情報をつけて一覧で管理できる。  
・GPSトレースデータを速度/距離、標高/距離などのグラフ表示をする  
・マークの登録ができ、塘路位置への地図の移動ができる。  
・写真に位置情報が記録されていれば写真の撮影値を地図上に示すことができる。

#### 右上のオプションボタンで使用できる機能  
**地図情報** : 表示中の地図の情報を表示  
**登録画面** : 表示画面の登録と呼び出し  
**GPSトレースリスト** :  GPSトレースリストの表示  
**マーク操作** : マークの登録や位置表示などのメニュー  
**写真の位置** : 選択した写真の位置に移動  
**地図データ一括取込み** : 表示画面の地図データをズームで3段階分をまとめて読み込む
**オフライン** : 地図データの新規取得を停止   
**地図データ編集** : 地図データの設定の変更や新規地図データの登録  
**アプリデータ情報** :  取得した地図データの数(セル数)とそのサイズを表示    
**ストレージパーミッション** :  アプリのストレージの許可状態を表示  
**アプリケーションパーミッション** :  アプリの権限の許可状態を表示

#### インストール方法
実行ファイルのダウンロードは[mapapp-debug.apk](mapapp-debug.apk)をダウンロードする。  
<img src="image/download.png" width="80%">
(スマホでダウンロードする場合は中央の[View raw]をクリックするとダウンロードができる)  

・スマホを開発者オプションの設定にする(Android12/13)  
1.	スマホの設定アプリを開く
2.	デバイス情報 (端末情報)をタップ
3.	下のほうに「ビルド番号」という項目があるので、10回程度タップする
4.	設定アプリの最初に戻って「システム」をタップ
5.	「開発者向けオプション」が表示されるのでタップ
6.	一番上の「開発者向けオプションの使用」をタップして開発者向けオプションを有効化する

・インストール  
GoogleのFilesアプリでダウンロードしたファイル(mapapp-debug.apk)をタップするか、ファイルを選択してから右側の点をタップするとメニューが表示されるのでインストールを選択するとインストールが開始される。  

・起動時の設定  
アプリ起動時にファイルアクセスの設定が有効になっていないと「ファイルアクセス」の設定画面が開くので、そこでアプリ(いろんな地図)を選択して「全ファイルの管理権を付与」を有効にする。  
・その他のアクセス権の設定  
アンドロイドのホーム画面から「設定」を開いて「アプリ」「いろんな地図」を選択した画面で「権限」を選択して「許可しない」項目にある権限(位置情報、身体活動)を選択して権限の許可をおこなう。  
これが設定されていないとGPSトレースや歩数計測が使用できない。  

### メモ
・方位があっていないとき 
　スマホの方位があっていない時も発生する。方位を確認してあっていない時はスマホを8の字を横にしたように動かすと較正される  
・GPSの測位方法  
  google play service(FusedLocationProviderClient)を使用  
  これを使うとGPSで即位できない時に通信回線より位置を測位する  
  GPSが使えないと場所によっては大幅に制度が下がる  
・地図データ  
 地図データは 256x256 のビットマップデータをタイル状に並べて表示している  
 国土地理院の地図の場合、ズームレベル 0 ～ 18 で使用でき数字が大きいほど拡大される  
 ズームレベル 0 の場合は世界地図が一枚のビットマップで表示され,ズームレベル 1 では 4枚のビットマップであらわされる  
 ズームレベル n では 2のn乗枚のビットマップで全世界が表示されるようになっている  
 地図データは国土地理院の地図のほかにもオープンストリートマップなどフリーで使用できる地図がある  
 気象庁の天気情報のデータも同じ方式のデータで使用することができる
